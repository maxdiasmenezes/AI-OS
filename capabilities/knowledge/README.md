# Knowledge

AI employee focused on managing and surfacing personal knowledge and learning.

This package is reserved for that future, higher-level AI-employee
capability and is not yet implemented. It is distinct from
`capabilities/knowledge_commands/` (Milestone 37), the deterministic,
model-free `/knowledge` command layer over the local knowledge base
(`kernel/knowledge_base/`) - see that package's README for the command
grammar and behavior.
